# Empirical feature prompt

Read `ai/context/` and turn the requested outcome into one small, independently
verifiable feature. Use `empirical new <numbered-id> --profile quick` for narrow,
understood work or `--profile strong` for broad, ambiguous, risky, or durable
contract changes.

Write observable acceptance criteria with stable IDs. Mark only visual browser
behavior with `[UI]`. Include scope, non-goals, dependencies, risks, and the
commands or capabilities that will prove completion.
