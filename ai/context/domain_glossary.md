# Domain Glossary

- **Protocol:** The vendor-neutral repository contract shared by all clients.
- **Client:** A CLI, IDE, agent, or service that reads or advances an SDD.
- **Profile:** A configured workflow shape, currently Quick or Strong.
- **Phase:** One state in the selected profile's lifecycle.
- **Transition:** A revision-checked movement between phases.
- **Criterion:** One observable acceptance condition from a specification.
- **Evidence:** A portable record proving or disproving one criterion.
- **Capability:** An optional implementation of testing, browsing, reviewing,
  or delivery behavior.
- **Gate:** A deterministic decision that permits, blocks, or escalates a
  transition.
- **Projection:** Disposable derived state, such as an IDE's SQLite index.
- **Delivery:** Configured post-review effects such as commit, push, or pull
  request creation.
