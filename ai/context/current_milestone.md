# Current Milestone

## M1 — Portable resumable core

Deliver a public repository containing:

- A neutral protocol and JSON schemas.
- Non-destructive Empirical v1 discovery and adoption.
- Quick and Strong lifecycle profiles.
- A filesystem state/event store with revision checks and recovery.
- Criterion-bound test, browser, screenshot-review, and code-review evidence.
- A configurable automatic loop with bounded repair attempts.
- Guarded commit, push, and pull-request delivery.
- A standalone CLI and embedding API.
- Conformance tests proving operation without a host runtime or SQLite.

Product-specific host integrations are intentionally outside M1.
